# SimpleInstaller

Schlanker Windows Installer Builder mit Python 3.12+ und PySide6.
Erstellt wiederverwendbare `.installer`-Pakete und installiert Dateien,
Benutzerkonfigurationen, Templates und Desktop-Verknüpfungen ohne Installer-Framework.

Projekt, Beispiel und Anleitung: [installer_builder](installer_builder/README.md).
